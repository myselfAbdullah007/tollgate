## Additional audit finding and remediation

The first Node 22 clean install reported ten moderate audit entries, all propagated
from minimatch 10.2.6 through the lint dependency tree. The underlying
[GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249) affects
minimatch >=7,<11.0.1. The package manager proposed downgrading Next's lint config
and ESLint with a forced major change. That was not applied.

A scoped npm override replaces only `minimatch@^10.0.0` with patched 11.0.8.
Consumers on unaffected 3.1.5 retain that version and API. Node 22 satisfies the
patched version's engine range. This crosses a transitive major boundary, so lint,
TypeScript, clean install, build and browser validation are required. Remove the
override when upstream lint packages directly permit a patched version. Final
npm audit reports zero findings at the recorded execution time; this is not an
independent security audit or a guarantee against future advisories.
